# Dwayne George Nixon — Portfolio

A responsive, buildless portfolio for Dwayne George Nixon, computer engineer, researcher, and builder. It presents selected projects, published research, education, leadership, credentials, and a downloadable CV.

## Run locally

From this folder, start a static server:

```powershell
python -m http.server 4173
```

Then open <http://127.0.0.1:4173>.

## Site files

- `index.html` — page structure, metadata, and project sections
- `styles.css` — responsive layout, color system, and animations
- `app.js` — project data, page transitions, and navigation behavior
- `assets/` — project artwork, social preview, favicon, and downloadable CV

The education section links to its image and logo sources. Project concept art is labelled as illustrative. The CV PDF is included as supplied.
